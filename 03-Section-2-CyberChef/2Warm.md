# 2Warm

**Category:** CyberChef  
**Difficulty:** Easy  
**Platform:** picoCTF 2021

## Challenge Description

The challenge requires converting a decimal number into its binary representation.

## Objective

Convert the given decimal number into binary.

## Solution

The challenge provided the decimal value:

```
42
```

I converted the value into binary using an online decimal-to-binary converter.

The resulting binary value was submitted to complete the challenge.

## Tool Used

- Decimal to Binary Converter
