# Bases

**Category:** CyberChef  
**Difficulty:** Easy  
**Platform:** picoCTF 2021

## Challenge Description

The challenge provides Base64-encoded data that must be decoded.

## Objective

Decode the Base64 encoded string.

## Solution

The provided text appeared to be Base64 encoded.

I opened **CyberChef**, selected the **From Base64** recipe, and pasted the encoded text into the input panel.

CyberChef decoded the input and revealed the required output, which was submitted as the flag.

## Tool Used

- CyberChef

## Recipe

```
From Base64
```

## Key Takeaway

Base64 is an encoding scheme, not an encryption algorithm. It is commonly used to represent binary data as ASCII text for storage and transmission.
