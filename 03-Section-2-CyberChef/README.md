# Section 2 – CyberChef

This section contains my solutions and write-ups for the **CyberChef** challenges from the picoCTF Challenge Library.

CyberChef is a browser-based toolkit widely used in **Cybersecurity**, **Digital Forensics**, **Incident Response**, and **CTF competitions** for encoding, decoding, data transformation, encryption, hashing, and format conversion. These challenges helped me become familiar with common encoding schemes and number system conversions frequently encountered during security assessments.

## Overview

The CyberChef section introduces fundamental data manipulation techniques, including:

- Caesar Cipher (ROT13)
- Base64 Decoding
- Hexadecimal to Decimal Conversion
- Decimal to Binary Conversion

These concepts form the foundation for many cryptography, malware analysis, reverse engineering, and forensic challenges.
