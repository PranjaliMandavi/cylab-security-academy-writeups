# Warmed Up

**Category:** CyberChef  
**Difficulty:** Easy  
**Platform:** picoCTF 2021

## Challenge Description

The challenge provides a hexadecimal value that must be converted to another number representation.

## Objective

Convert the given hexadecimal value to its decimal equivalent.

## Solution

The challenge provided the hexadecimal value:

```
0x3D
```

I converted the hexadecimal value to decimal using an online hexadecimal converter.

The decimal result was then submitted to obtain the flag.

## Tool Used

- Hexadecimal to Decimal Converter
